About QuickNotes

QuickNotes is a lightweight, minimalist web application designed to help you capture ideas before they disappear.

Our Mission

We believe that note-taking should be friction-free, fast, and accessible anywhere. Built during the Web Foundations module, this project demonstrates core HTML layout, semantic structuring, and future-proof DOM targeting.
